# Notebook to Bedside: MLOps Plan for a Pediatric Hospital

A one-page plan for taking clinical machine learning models from development
into production, written for the ML Ops Engineer II role at Boston Children's
Hospital.

**View the page:** https://mir-m-abdullah.github.io/bch-mlops-plan/

## What it covers

- A six-stage path from data ingestion through dbt transformation, MLflow
  tracking, validation, deployment, and drift monitoring
- A validation gate that reports model performance by pediatric age band
- A 30/60/90-day plan for the first three months in the role

Built from the public job posting only, so tool names are examples of the
pattern rather than assumptions about internal systems.
